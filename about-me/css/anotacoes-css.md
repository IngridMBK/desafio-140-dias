# Minhas anotações de CSS

## Flexbox

```css
.flex-test {
  display: flex; /* ativa o Flexbox */
  flex-direction: row; /* direção principal */
  justify-content: center; /* organiza no eixo principal */
  align-items: center; /* organiza no eixo transversal */
  height: 300px;
  border: 2px solid black;
  gap: 50px; /* espaço entre os itens */
  flex-wrap: wrap;
  /* justify-content: trabalha no eixo principal -> horizontal ou vertical / row ou column */
}
```
